# Navigation Drawer

This document describes the navigation drawer introduced into the application shell, its behavior, and the components involved.

## 1. Overview

The application gains a slide-in navigation drawer, opened by a hamburger button placed on the **left side of the navigation bar** (before the brand link). The drawer is only available to **authenticated users** — the hamburger button is not rendered when no one is logged in.

## 2. Behavior

- A hamburger button (`bars` icon) is rendered in the header's `start` slot, to the left of the brand link.
- Clicking the hamburger opens a drawer sliding in from the left (`placement="start"`).
- The drawer supports light dismiss (clicking the backdrop closes it) and the built-in close button / Escape key.
- The drawer contains:
  - **Navigation links** (top): currently only a link to the Dashboard page (`/dashboard`). Clicking it closes the drawer and navigates via the SPA router (`navigateTo`).
  - **Footer** (bottom):
    - Info about the currently logged-in user: name and email (from `loginQuery.data`).
    - A **Logout** button that closes the drawer, calls `signOut()`, and redirects to `/login`.
- Visibility: `app-shell` observes `loginQuery`; the `<app-nav-drawer>` element is rendered only when `loginQuery.data` is defined (user is logged in). It appears after a successful login and disappears after logout.

## 3. Components

### 3.1. `app-nav-drawer` (`src/components/layout/app-nav-drawer.ts`)

New Lit component encapsulating both the hamburger trigger button and the `wa-drawer`:

- Property `user?: User` — the currently logged-in user, passed in from `app-shell`.
- Internal state `open: boolean` — drawer visibility, synced with the drawer's `wa-hide` event so backdrop/Escape/close-button dismissals are tracked.
- Uses WebAwesome components: `wa-button`, `wa-drawer`, `wa-icon`.

### 3.2. `app-header` (`src/components/layout/app-header.ts`)

- Added a named slot `start` rendered before the brand link, wrapped together with it in a `.start` flex container. This is where the hamburger button is slotted.

### 3.3. `app-shell` (`src/app/app-shell.ts`)

- Observes `loginQuery` in `render()` so it re-renders on auth status changes.
- Conditionally renders `<app-nav-drawer slot="start" .user=${currentUser}>` inside `<app-header>` only when a user is logged in.

### 3.4. `web-components.ts` (`src/components/ui/web-components.ts`)

- Registers the additional WebAwesome components: `drawer` and `icon`.

## 4. Future Extensions

- Add further navigation links to the drawer's `<nav>` as new pages are introduced.
- The footer user info can be extended (e.g., avatar, role) once the `User` model grows.
