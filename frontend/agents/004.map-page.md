# Leaflet Map Page

This document describes the protected Leaflet and OpenStreetMap page added to the application.

## 1. Page

A new `map-page` Lit component is available at `/map`.

- The route is protected by the existing authentication guard.
- The page displays a responsive full-width map in a card-like container.
- Leaflet initializes with Warsaw, Poland as the default view (`52.2297, 21.0122`) and zoom level `12`.
- Map tiles are loaded from OpenStreetMap:
  - `https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png`
- The required OpenStreetMap attribution is displayed inside the map.
- The Leaflet map instance is removed when the page is disconnected.
- Zoom and fade animations are disabled to prevent transient 1-pixel tile seams and black lines between scaled tiles.
- Leaflet tile blending is normalized to `mix-blend-mode: normal` and the tile container has `isolation: isolate` to avoid Chromium rendering seams.

## 2. Navigation

The authenticated navigation drawer now contains a second link:

- **Map** — navigates to `/map` using the SPA router and closes the drawer.

The link is available only while the drawer itself is visible to authenticated users.

## 3. Dependencies

- `leaflet` supplies the map implementation.
- `@types/leaflet` supplies TypeScript declarations.
- Leaflet's CSS is imported by the map page component.
- Leaflet's stylesheet is embedded into the component's shadow root (via Vite's CSS `?inline` import) so tile positioning and controls work correctly inside the Lit shadow DOM.
